# Workshop Sesi 2

Project ini berisi latihan JavaScript dasar mengenai object literal, function declaration, dan constructor function.

## File yang ada

- `index.html` : file HTML yang memuat script JavaScript
- `index.js` : file JavaScript berisi contoh objek dan fungsi

## Isi latihan

### 1. Object Literal
Membuat objek `mobil` dengan properti seperti nama, merek, tipe mobil, warna, dan method untuk menampilkan aksi mobil.

### 2. Function Declaration
Membuat objek kucing menggunakan function `buatObjectKucing(nama, jenis, warna)`.

### 3. Constructor Function
Membuat objek kursi menggunakan constructor `Kursi(jenis, warna, bahan)`, lalu menampilkan hasil menggunakan `alert()`.

## Cara menjalankan

### Opsi 1: Buka di browser
1. Buka file `index.html` di browser
2. Tekan F12
3. Pilih tab Console untuk melihat output JavaScript
4. Untuk tugas kursi, popup alert akan muncul di halaman

### Opsi 2: Jalankan melalui terminal
```bash
node index.js
```

Perintah tersebut akan menampilkan output dari objek mobil dan kucing di terminal.

Contoh output di console:

## Catatan

File HTML di project ini berisi beberapa contoh struktur HTML yang memanggil file JavaScript yang sama. Biasanya untuk latihan sederhana, cukup buka file `index.html` di browser untuk melihat hasilnya.
